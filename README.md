## Featured Projects

### Discovery Accelerator &nbsp; ![](https://img.shields.io/badge/Company_Project-Psiog_Digital-8A2BE2?style=flat-square)
An AI-powered internal knowledge assistant that turns fragmented consulting documents (SOWs, transcripts, diagrams) into a **provable, source-cited, project-scoped answer engine**. Closed to the open internet — every answer is grounded only in ingested documents and links back to its source.

- **Contradiction detection cascade** — embedding retrieval → bidirectional NLI pre-filter → a symmetric LLM judge run in both orderings to eliminate order-bias, flagging source/temporal/metric/scope conflicts across documents.
- **3-layer Checkpoints with grounded abstention** — questions stay honestly open when evidence is weak instead of being force-answered.
- **Async ingestion pipeline** (FastAPI → Celery + Redis) with an **Azure OpenAI → Groq** offline fallback across every LLM call site, plus a permanent evaluation harness for judge precision/recall and grounding accuracy.
